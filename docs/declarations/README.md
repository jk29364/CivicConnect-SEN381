# AI Usage declaration and PR creation guidelines
## Before you commit a branch to a pull request: 
0. (if applicable) Fill in an entry to `AI_register`
1. Download the `templates.zip` folder
2. Open the appropriate template
3. Check the box with the correct details filled in
4. Press Ctrl+P
5. Save as PDF
6. Name it with the following convention:\
   AI used: `YYYY-MM-DD_BranchName_AI.pdf`\
   No AI used: `YYYY-MM-DD_BranchName_NAI.pdf`

7. Upload it in `/declarations/`

## How to fill in `AI_register`
AI register entries cover an entire branch. Format as follows:

`01: [AI name] was used by [Member Name and Surname] to [Description]`

If multiple AI services were used, format as follows:

`01: a: [AI name] was used by [Member Name and Surname] to [Description]`\
&emsp;&emsp;&nbsp;`b: [AI name] was used to [Description]`
